# ApplyLog · 지원 기록

채용 공고를 여러 곳에서 확인하다 보면 지원 마감일과 다음 할 일이 흩어집니다. ApplyLog는 회사별 지원 정보를 한곳에서 관리하는 Windows 데스크톱 앱입니다.

## 실행

같은 폴더에 있는 `ApplyLog.cmd`를 더블클릭합니다. Windows PowerShell과 WinForms를 사용합니다.

1. **새 지원**을 누르고 회사, 직무, 마감일과 메모를 입력한 뒤 **저장**합니다.
2. 목록에서 기록을 선택하면 내용을 수정하거나 지원 상태를 변경할 수 있습니다.
3. 검색어와 상태 필터를 함께 사용해 원하는 기록을 찾습니다.

## 구현

- 상태는 관심, 지원 완료, 면접, 합격, 종료로 관리합니다.
- 가장 가까운 마감일을 위에 표시하고, 상단에서 오늘부터 7일 뒤까지 마감이 잡힌 관심 공고 수를 확인할 수 있습니다.
- 기록은 `%LOCALAPPDATA%\ApplyLog\applications.json`에 저장됩니다. 저장 시 임시 파일을 완성한 다음 기존 파일을 교체합니다.
- 한 Windows 세션의 중복 실행을 막습니다. 사용자별 로컬 파일로 동작하며 기기 간 동기화는 제공하지 않습니다.

## 검증

PowerShell에서 `powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\ApplyLog.ps1 -Check`를 실행하면 임시 파일에서 한글 저장과 다시 읽기, 검색·상태 필터, 마감일 순서, 수정과 삭제를 검증합니다.

## 개발 기록

첫 실행 버전은 Codex와 함께 제작했습니다. 이후 직접 결정한 기능과 테스트 결과는 변경 이력에 남깁니다.
